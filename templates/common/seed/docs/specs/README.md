# Specs

Every non-trivial change starts as a spec in this folder. `/factory:spec` writes them.

- `NNNN-short-slug.md`: the spec (problem, acceptance criteria, scope).
- `NNNN-short-slug.plan.md`: the implementation plan (`/factory:plan`).

Specs are short (one screen is ideal). They're written for the reviewer as much as for
Claude: a PR is reviewed against its spec's acceptance criteria.

Number specs sequentially. The number links the spec, its plan, the branch and the PR.
